# راهنمای ادامه پروژه توسط توسعه‌دهنده یا AI

## متن آماده برای شروع حساب جدید

> مخزن shokri88/Asemane-NetCore را دریافت کن. ابتدا AGENTS.md، README و docs/STATUS.fa.md، docs/DECISIONS.fa.md و docs/VALIDATION.fa.md را بخوان. معماری MVC ساده، SQL Server، EF Core و Identity را حفظ کن. قالب مرجع shokri88/Asemane-UI است. سایت عمومی فقط انگلیسی است و فارسی برای فاز بعد برنامه‌ریزی شده. فایل‌ها روی سرور خارج wwwroot ذخیره می‌شوند. قبل از تغییر، وضعیت واقعی کد و Migration را بررسی کن؛ کارهای انجام‌شده و کارهای باز را با مستندات تطبیق بده و پس از تغییر، مستندات و تست‌های مرتبط را همان commit به‌روز کن. هیچ رمز یا محتوای واقعی را حدس نزن.

## راه تشخیص وضعیت واقعی

1. `git log` و شاخه/commit فعلی را بررسی کنید.
2. نسخه SDK و package را از csproj/global.json بخوانید؛ به حافظه چت اتکا نکنید.
3. build و test را اجرا کنید. Migration pending را بررسی کنید.
4. رفتار فرم‌ها/routeهای مورد تغییر را با docs/ROUTES تطبیق دهید.
5. در صورت تغییر تصمیم، DECISIONS را با دلیل به‌روز کنید؛ مستند قدیمی را به‌عنوان واقعیت فعلی تکرار نکنید.

## نقاط توسعه بعدی

- فارسی: Languages، ترجمه UI، فرم Culture، Page Key و RTL عمومی.
- WYSIWYG: طراحی sanitizer معتبر و سیاست لینک/HTML پیش از Html.Raw.
- فایل: decoder/بهینه‌سازی/thumbnail، cache version و اسکن متناسب با هاست.
- مدیریت: سطل زباله/بازیابی، ویرایش نقش و اطلاعات کاربر، Audit Log و پیش‌نمایش پیش‌نویس.
- production: تست SQL واقعی و IIS، تنظیم دامنه، backup، HTTPS و ایندکس.

## رمزها و داده‌ها

هیچ رمز قابل بازیابی از این مخزن وجود ندارد. User Secrets به کامپیوتر توسعه‌دهنده وابسته‌اند. برای انتقال واقعی سایت علاوه بر git به backup SQL و فایل‌ها و تنظیمات امن نیاز دارید. کلید DataProtection نیز در محل پایدار نگهداری شود.

## مستندسازی پس از commit

به‌روزرسانی مستندات بخشی از کار توسعه است، نه یک وعده اتوماسیون اجراشونده بعد از هر commit. GitHub Actions، build/test/model validation را اجرا می‌کند. تاریخچه قطعی کد در git و خلاصه رفتار در CHANGELOG/STATUS نگهداری می‌شود.
