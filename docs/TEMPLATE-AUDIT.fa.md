## اختلاف پیدا و اصلاح‌شده

در فهرست بلاگ، افزودن لینک به عنوان باعث ارث‌نبردن اندازه/وزن فونت و ارتفاع سطر H4 شده بود؛ اندازه لینک ۱۶px و تیتر منبع ۲۰px بود. `font:inherit` فقط روی همان لینک اعمال شد. این اصلاح فاصله متن‌ها و ارتفاع کارت‌ها را در هر سه عرض با مرجع برابر کرد؛ CSS اصلی تغییر نکرد. بررسی اولیه با این اختلاف واقعاً ناموفق بود و پس از اصلاح کل ماتریس موفق شد.

## روش و محدوده ادعا

fixture شامل ۱۲ پروژه (۹ Featured)، ۳ مقاله، ۶ عضو، یک صفحه عمومی و تصاویر نقش‌دار از قالب ارسالی است؛ داده واقعی تغییر نکرد. در reference فقط متن/URL، بدنه محتوا، تعداد رکورد و داده دسته‌بندی جایگذاری می‌شود و ظرف‌های HTML از منبع اصلی حفظ می‌شوند. منوی پنج‌گزینه‌ای، H1/صفحه‌بندی نامرئی SEO، شناسه داده‌ها و لینک‌های محتوا تغییرات مجاز قبلی‌اند. کلاس‌های غیرنمایشی record/comment عادی‌سازی شدند.

برای تطبیق ثابت CSS، script و loader در هر دو طرف حذف و مقایسه تعاملات در اجرای جداگانه انجام شد. برابری با داده یکسان به معنای تضمین ظاهر همه محتوای ممکن یا همه حالت‌های انیمیشن نیست. مرورگر فقط گواهی توسعه localhost را در context تست می‌پذیرفت و درخواست خارجی نقشه مسدود بود؛ نمایش زنده Google Maps و اجرای Migration روی SQL Server واقعی در این بازبینی آزموده نشد.
