# سئو و توسعه چندزبانه

## خروجی سئو فعلی

| مورد | پیاده‌سازی |
|---|---|
| HTML سمت سرور | Razor؛ محتوا برای نمایش به JavaScript وابسته نیست |
| title و description | قابل ویرایش برای هر ترجمه؛ fallback عنوان/خلاصه |
| canonical | از Site:BaseUrl و مسیر استاندارد؛ نه Host دریافتی کاربر |
| robots meta | noindex برای تنظیم محیط، صفحه مشخص و صفحات فیلتر/شماره‌دار |
| robots.txt | عدم ایندکس محیط توسعه؛ Disallow مدیریت در production |
| sitemap | فقط ترجمه فعال/منتشرشده/غیرحذف/بدون NoIndex؛ lastmod با timezone |
| OG و Twitter | عنوان، توضیح، تصویر کاور یا لوگو و آدرس اصلی |
| JSON-LD | Organization/WebSite عمومی، Article برای مقاله، WebPage برای سایر محتوا و BreadcrumbList |
| hreflang | فقط ترجمه فعال، منتشرشده و قابل ایندکس؛ فارسی فرضی ساخته نمی‌شود |
| تصاویر | Alt محتوایی، lazy در جایگاه‌های اصلی قالب و نام داخلی امن؛ ابعاد/کلاس‌های نمایشی قالب حفظ می‌شوند |
| تغییر URL | SlugRedirect و پاسخ ۳۰۱ به آدرس فعلی |
| محتوا و عنوان‌ها | یک H1 از عنوان، امکان H2/H3/H4 در HTML پاک‌شده |
| صفحه ناموجود | 404 واقعی، نه 200 با متن «پیدا نشد» |
| امنیت پنل از خزش | X-Robots-Tag و meta noindex، Cookie و کنترل نقش |

این موارد زیرساخت فنی‌اند و تضمین رتبه، امتیاز Lighthouse یا Rich Result گوگل نیستند. schema پروژه فعلاً WebPage است؛ ادعای LocalBusiness، review، rating، قیمت یا نشانی تأییدنشده تولید نمی‌شود.

## تنظیم دامنه و شروع ایندکس

در محیط production از تنظیمات امن استفاده کنید:

```text
Site__BaseUrl=https://YOUR-REAL-DOMAIN
Site__IndexingEnabled=true
AllowedHosts=YOUR-REAL-DOMAIN;www.YOUR-REAL-DOMAIN
```

BaseUrl فقط origin بدون path/query است. مقدار example.com حتی با flag روشن قابل ایندکس نمی‌شود. پس از تست، robots و sitemap را باز و URLهای واقعی را بررسی کنید. ریدایرکت www/بدون www و HTTP به HTTPS را در هاست با دامنه canonical هماهنگ کنید. تغییر URLهای سایت فعلی نیازمند فهرست آدرس‌های واقعی آن سایت و نگاشت مهاجرت است؛ این نسخه فقط اسلاگ‌های تغییرکرده داخل CMS را مدیریت می‌کند.

## اطلاعات مشترک و ترجمه

- مشترک: شناسه محتوا، دسته، سال، مساحت، تصاویر، ترتیب و Featured.
- ترجمه‌شونده: عنوان، اسلاگ، متن، خلاصه، سمت، موقعیت، وضعیت متنی پروژه، نویسنده و متا.
- Alt/Caption و نام دسته/آدرس تماس نیز ترجمه مستقل دارند.
- انتشار مستقل هر ترجمه مانع ایندکس صفحه خالی فارسی می‌شود.
- آدرس انگلیسی از ابتدا `/en/...` است؛ برای اضافه‌شدن `/fa/...` انگلیسی تغییر نمی‌کند.

## چک‌لیست فاز فارسی

1. ترجمه منو، عنوان فهرست‌ها، پیام عمومی، breadcrumb و footer در منابع UI پیاده شود؛ امروز متن UI انگلیسی است.
2. فرم مدیریت ترجمه و انتخاب Culture اضافه شود؛ فرم فعلی عمداً فقط en را قبول می‌کند.
3. ترجمه دسته‌ها، تنظیمات و Alt تصاویر تکمیل شود.
4. Pages about/contact فعلاً Key/Slug انگلیسی ثابت دارند؛ برای slug فارسی باید resolve صفحه از Key بازطراحی و ریدایرکت مسیر مناسب اضافه شود.
5. استایل RTL و فونت فارسی عمومی کامل و بررسی موبایل شود. صرف dir=rtl در layout به معنای تکمیل UI فارسی نیست.
6. سپس fa در Languages.Enabled فعال شود؛ ترجمه آماده مستقل منتشر شود.
7. hreflang متقابل، canonical هر زبان، sitemap و 404 ترجمه غایب تست شود.

در این فاز fallback خودکار متن انگلیسی به‌عنوان صفحه فارسی منتشر نمی‌کنیم.

## تصاویر اختصاصی پروژه

تصویر اجتماعی پروژه از نقش بنر و سپس تصویر مربع پروژه انتخاب می‌شود؛ برای تصاویر عمومی قدیمی fallback وجود دارد. ویرایشگر متن H1 جدید تولید نمی‌کند و HTML کاربر پیش از نمایش پاک‌سازی می‌شود. canonical و سیاست noindex صفحات دسته/صفحه‌بندی تغییر نکرده است.
