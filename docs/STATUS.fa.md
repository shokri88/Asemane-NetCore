# وضعیت پروژه

تاریخ: ۱ نوامبر ۲۰۲۶ / ۱۰ آبان ۱۴۰۵. نسخه: پایه عملیاتی فاز اول CMS انگلیسی.

## انجام‌شده

- Solution قابل بازکردن در VS2026 و پروژه .NET 10 MVC با Razor View.
- SQL Server و EF Core، Initial Migration و SQL idempotent بررسی‌پذیر.
- Identity، Cookie امن، نقش Admin/Editor، ورود/خروج، قفل حساب، ایجاد کاربر، تغییر رمز و غیرفعال‌کردن ویرایشگر.
- مدیریت پروژه/مقاله/صفحه/تیم با فهرست جدا، جست‌وجو، وضعیت، sort و صفحه‌بندی.
- فیلدهای اختصاصی پروژه، دسته‌بندی پروژه/مقاله، زمان اولین انتشار و حذف نرم.
- جلوگیری از ویرایش هم‌زمان محتوا با Version و محافظت صفحات سیستمی.
- صفحه مستقل گالری با آپلود، Cover، Alt، Caption، ترتیب و حذف واقعی تصویر.
- ذخیره فایل بیرون wwwroot با نام تصادفی، کنترل حجم/پسوند/هدر و محافظت رسانه پیش‌نویس.
- تنظیمات برند، لوگو، تماس، موقعیت، آمار و متای خانه.
- عمومی انگلیسی: خانه، فهرست/فیلتر پروژه، جزئیات و گالری، ژورنال، مقاله، صفحات، تیم و تماس.
- SEO: SSR، متا، canonical، OG/Twitter، schema، hreflang فقط معتبر، robots/sitemap و ۳۰۱ اسلاگ.
- متن امن با پاراگراف، H2/H3 و فهرست؛ HTML کاربر اجرا نمی‌شود.
- پنل Bootstrap RTL محلی، واکنش‌گرا و با تاریخ شمسی/اعداد نمایشی فارسی.
- مدل ترجمه جدا از اطلاعات مشترک؛ فارسی عمومی هنوز غیرفعال.
- ۱۵ آزمون خودکار موفق، بررسی browser در دو عرض و workflow CI.
- مجموعه مستندات فارسی، راهنمای تحویل به AI و قواعد تغییر مستندات در AGENTS.

## برای راه‌اندازی روی سیستم کاربر

1. دریافت repo و بازکردن Asemane.sln.
2. تنظیم Connection String و رازهای Bootstrap طبق SETUP.
3. اجرای bootstrap روی SQL Server واقعی؛ این محیط SQL Server فعال نداشت.
4. اجرای HTTPS، ورود پنل و ثبت اطلاعات واقعی استودیو/محتوا/تصاویر.
5. بررسی نهایی ظاهر با تصاویر و متن واقعی و سپس Deploy روی هاست مقصد.
