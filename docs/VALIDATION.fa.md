# اعتبارسنجی نسخه اولیه

تاریخ: ۱ نوامبر ۲۰۲۶. محیط: Linux، SDK 10.0.403، Runtime 10.0.14.

## نتایج

| بررسی | نتیجه |
|---|---|
| build پروژه و Razor Viewها | موفق، بدون خطا و هشدار |
| آزمون‌های xUnit + ASP.NET TestServer | ۱۶ آزمون، همه موفق |
| EF pending model changes | بدون تغییر مدل ثبت‌نشده |
| تولید Initial Migration و SQL idempotent | موفق |
| ترجمه Query تولیدی به SQL Server و تولید SQL Identity/CMS | موفق؛ بدون اتصال زنده به SQL |
| NuGet vulnerable شامل وابستگی غیرمستقیم production | آسیب‌پذیری شناخته‌شده‌ای در فهرست فعلی گزارش نشد |
| syntax دو فایل JavaScript | node --check موفق |
| مرورگر desktop/mobile | ۵ صفحه در عرض ۱۴۴۰ و ۳۹۰؛ بدون overflow افقی کل صفحه و خطای JS |
| منوی عمومی موبایل و offcanvas پنل | بازشدن با کلیک بررسی شد |
| SQL Server واقعی، IIS و اطلاعات کسب‌وکار | در این محیط قابل اجرا نبود؛ مرحله استقرار |

یک هشدار وابستگی غیرمستقیم System.Security.Cryptography.Pkcs نسخه 9.0.11 در Restore اولیه دیده شد؛ نسخه 10.0.14 صریح ثبت شد و audit بعدی هشدار نداشت. این بررسی جایگزین به‌روزرسانی و audit دوره‌ای نیست.

## پوشش تست

- پیش‌نویس و fa غیرفعال پاسخ عمومی ندارند.
- canonical از دامنه تنظیم‌شده ساخته می‌شود؛ sitemap پیش‌نویس ندارد و hreflang فارسی ساختگی تولید نمی‌شود.
- مدیریت ناشناس به ورود هدایت می‌شود؛ POST بدون anti-forgery رد می‌شود.
- Editor اجازه کاربران/تنظیمات ندارد.
- ذخیره فرم واقعی محتوا، ریدایرکت ۳۰۱ اسلاگ قبلی و جلوگیری از بازنویسی نسخه قدیمی.
- متن script به HTML فعال تبدیل نمی‌شود.
- آپلود واقعی PNG روی دیسک، رد فایل HTML با پسوند تصویر و محرمانه‌بودن تصویر پیش‌نویس.
- رندر صفحات پنل و حذف نرم محتوا.
- ساخت دسته، رد تکراری و ذخیره تنظیمات با فیلد اختیاری خالی.
- JSON-LD معتبر، نویسنده سازمانی به‌جای شخص فرضی و تاریخ دارای timezone.
- Query/DDL مربوط به SQL Server از مدل production تولید می‌شود.
- صفحات رندرشده یک H1 و بدون id تکراری هستند.
- نرمال‌سازی اسلاگ انگلیسی/فارسی و بررسی امضای فایل.

## روش مرورگر

HTML واقعی Razor از TestServer با داده آزمایشی استخراج و CSS/JS همان پروژه در Chromium headless نمایش داده شد. صفحات dashboard، content list، edit، home و project در desktop/mobile بررسی شدند. این آزمون ظاهر و رفتار کوچک JS است؛ ادعای تست اتصال مرورگر به SQL Server production نیست. داده seed تست وارد bootstrap یا دیتابیس اصلی نمی‌شود.

## تکرار

```powershell
dotnet build Asemane.sln -c Release
dotnet test tests/Asemane.Tests -c Release --logger "trx;LogFileName=tests.trx"
dotnet tool restore
dotnet ef migrations has-pending-model-changes --project src/Asemane.Web
dotnet list src/Asemane.Web package --vulnerable --include-transitive
```

خروجی TRX تولید می‌شود اما در git ثبت نمی‌شود. GitHub Actions آن را به‌عنوان artifact نگه می‌دارد. اجرای workflow روی GitHub نتیجه مستقل دارد و باید از تب Actions مشاهده شود.

## بررسی لازم پیش از انتشار عمومی

روی SQL Server واقعی bootstrap را اجرا کنید؛ ایجاد، ویرایش، دسته، آپلود، انتشار، تغییر اسلاگ و سطح دسترسی را با محتوای واقعی بررسی کنید. سپس مسیر پایدار فایل‌ها، backup/restore، HTTPS، کلیدها، دامنه canonical و تنظیم ایندکس را روی هاست مقصد کنترل کنید. امتیاز Lighthouse و SEO رقابتی با داده واقعی هنوز محاسبه نشده است.

## نتیجه اجرای GitHub Actions پس از ثبت کد

اولین workflow روی commit `595e6e0` در [اجرای 41312924912](https://github.com/shokri88/Asemane-NetCore/actions/runs/41312924912) پیش از شروع job متوقف شد. پیام خود GitHub:

هیچ مرحله Build یا Test روی runner اجرا نشد؛ بنابراین این نتیجه، شکست تست کد نیست و CI موفق روی GitHub نیز ادعا نمی‌شود. ۱۵ تست و Release Build در محیط توسعه موفق بوده‌اند. رفع محدودیت Billing از تنظیمات حساب مالک انجام می‌شود و تغییری در تنظیمات مالی حساب داده نشده است. پس از رفع آن، همین workflow را دوباره اجرا کنید.

## اعتبارسنجی تفکیک Controller و View

پس از تفکیک Home، About، Contact، Project و Blog، Release Build با صفر هشدار و صفر خطا و هر ۱۶ تست موفق شدند. تست جدید مالکیت مسیرها را از ActionDescriptor، وجود View کامپایل‌شده مستقل، رندر هر پنج بخش، فهرست/جزئیات پروژه و بلاگ، صفحات دیگر، تیم و ۳۰۱ مسیر قدیمی about بررسی می‌کند. نمایش تیم فقط در درباره و اطلاعات تماس فقط در تماس نیز بررسی شد. تست‌های قبلی canonical، schema، انتشار، دسترسی و اسلاگ همچنان موفق‌اند. این تغییر فقط ساختار MVC را تغییر می‌دهد و Migration جدید لازم ندارد.

## حفظ قالب اصلی — ۲ نوامبر ۲۰۲۶

- مرجع: `shokri88/Asemane-UI@5c4149ebfb028c19fea918ec638246889607205b`، هفت فایل index/about/contact/workgrid/workdet/blog/blogdet.
- Release Build بدون هشدار و خطا؛ هر ۱۷ تست موفق، بدون skip. تست جدید checksum تمام دارایی‌های کپی‌شده، بارگذاری فایل‌ها از StaticFiles، اتصال متن/کاور/گالری/تیم/تلفن و آمار منتشرشده را بررسی می‌کند. تست‌های قبلی سئو، انتشار، CSRF و نقش‌ها همچنان موفق‌اند.
- EF pending model changes: هیچ تغییر مدلی نسبت به Migration وجود ندارد.
- ساختار DOM و کلاس‌های ظرف‌ها، ترتیب stylesheet و script و متن اسکریپت‌های inline با مرجع مقایسه شد. فقط تکرار رکوردها و جایگاه‌های داده نرمال شدند؛ H1 نامرئی سئو از مقایسه بصری حذف شد.
- در Chromium، هر هفت صفحه در عرض‌های ۱۴۴۰ و ۳۹۰ با مرجع دارای داده و تعداد رکورد یکسان مقایسه شدند؛ هر ۱۴ تصویر CSS/layout یکسان بود. برای این مقایسه قطعی، JS اجرا نشد و loader در هر دو طرف حذف شد؛ تصاویر محتوایی از تصویر محلی آزمایشی یکسان استفاده کردند. این نتیجه ادعای برابری همه حالت‌های تعاملی یا داده‌های واقعی نیست.
- فایل‌های بررسی و تصاویر اجرای جاری بیرون مخزن در `/workspace/template-validation` هستند؛ داده تست وارد دیتابیس واقعی یا bootstrap نشده است. برای استخراج HTML تست‌ها متغیر `ASEMANE_RENDER_DIR` را قبل از `dotnet test` تنظیم کنید.
- اتصال واقعی SQL Server و گردش کار روی هاست مقصد در این تغییر تأیید نشده است. CSS/JS اصلی با خطاهای قبلی حفظ شده‌اند؛ نمونه شناخته‌شده `document.addtListener` در شمارنده درباره است. اصلاح رفتار قالب نیازمند درخواست مستقل است.

در بررسی جداگانه JavaScript روی HTML رندرشده، loader در هر هفت صفحه بسته شد؛ شش صفحه بدون خطای JS بودند و صفحه درباره فقط خطای قدیمی `addtListener` را داشت. گالری پروژه از رسانه داده‌شده مقدار گرفت و اسلایدها با منطق اصلی قالب ساخته شدند.

## تغییرات درخواستی — ۱۰ نوامبر ۲۰۲۶

- Release Build: صفر خطا و صفر هشدار. هر ۲۷ تست موفق؛ بدون skip. تست‌های جدید منوی مشترک پنج‌گزینه‌ای، تفکیک نقش تصاویر، تک‌تصویری بودن جایگاه‌ها، گالری چندتصویری، ورودی Role نامعتبر، فیلتر کل مجموعه/صفحه‌بندی، تماس و نقشه، ذخیره HTML و Featured را پوشش می‌دهند. تست‌های قبلی CSRF، دسترسی، رسانه پیش‌نویس، اسلاگ و سئو همچنان برقرارند.
- سناریوهای XSS شامل script/iframe، event handler، SVG/MathML، scheme رمزگذاری‌شده javascript و CSS خطرناک بررسی شدند. فرم نامعتبر، مقدار خام ModelState را به ویرایشگر برنمی‌گرداند؛ متن قدیمی همچنان encode می‌شود.
- بررسی pending model changes موفق است. SQL Server upgrade script از EF تولید شد؛ Up فقط ستون اضافه می‌کند و ظرفیت Phone را افزایش می‌دهد. index عمومی رسانه باقی است. Migration اولیه بازنویسی نشده و این ارتقا روی SQL Server واقعی اعمال نشده است.
- Chromium با Kestrel واقعی روی HTTPS و SQLite fixture: بازشدن منوی موبایل، انتخاب دسته و بازگشت All Work، راه‌اندازی Summernote، حفظ متن قبلی، ذخیره تیتر/متن ضخیم/جدول از فرم و مشاهده در صفحه عمومی، خاموش‌کردن Featured، آپلود تصویر با نقش گالری و ذخیره تماس/کد پستی/URL نقشه از فرم واقعی موفق بود. این گردش کار صفحه‌ها POST واقعی با CSRF و Cookie امن دارد و HTML ثابت یا پاسخ جعلی فرم نیست. خطای JavaScript در این سناریوها ثبت نشد.
- مرورگر گواهی توسعه localhost را برای همین تست می‌پذیرفت؛ بارگذاری خارجی نقشه گوگل در این بررسی مسدود شد. وجود iframe با URL و تنظیمات درست تأیید شد؛ نمایش محتوای زنده Google Maps یا SQL Server production ادعا نمی‌شود. خطای قدیمی شمارنده درباره خارج از این تغییر باقی است.
- تصاویر/نتایج اجرای جاری در `/workspace/change-validation` هستند. checksumهای CSS/JS/فونت‌های اصلی قالب همچنان در تست موفق‌اند. تنها اسکریپت‌های افزوده فیلتر و ویرایشگر در فایل‌های جدا هستند.

## تطبیق مجدد About و مدیریت تیم/آمار

- بررسی pending model changes موفق؛ SQL upgrade از EF تولید شده است. Migration قبلی دست‌نخورده است. اجرای Migration جدید روی SQL Server واقعی در این محیط انجام نشده است.
- روی Kestrel واقعی HTTPS با SQLite fixture، شش عضو آزمایشی و مقادیر آماری اصلی ۴۰/۱۰/۱۰/۲۰ رندر شدند. ساختار ظرف‌های About با فایل مرجع Asemane-UI@5c4149ebfb028c19fea918ec638246889607205b تطبیق داده شد؛ رکوردها و متن‌ها/URLهای داده نرمال شدند. منوی مشترک پنج‌گزینه‌ای از درخواست قبلی در هر دو طرف مقایسه ثابت نگه داشته شد.

- جدا از مقایسه ثابت، در صفحه واقعی شروع شمارنده هنگام ورود به viewport و رسیدن دقیق به مقدار نهایی تأیید شد. تغییر چهار عنوان/مقدار از فرم واقعی مدیریت و POST دارای CSRF، نمایش ۰/۴۲/۱۰۰۰۰۰۰۰۰۰/۱۲ و حالت reduced motion موفق بود؛ خطای JS ثبت نشد. دو تصویر افقی عضو در جزئیات و شش تصویر مربعی در About تأیید شدند.

## اصلاح نهایی تعداد تصاویر عضو

پس از پاسخ کاربر، تعداد به دو جایگاه اختصاصی مربع و افقی محدود شد. Build بدون هشدار/خطا، هر ۳۱ تست موفق و pending model changes خالی است. تست مستقل تعداد دو فایل/دو نقش، رد نقش ۸ و نقش پروژه برای تیم، یک بنر در جزئیات، و عدم نمایش افقی در کارت About را بررسی می‌کند. تست حفظ رسانه، SQL تبدیل نقش ۸ به عمومی را روی SQLite fixture اجرا و بقای StoredName و فایل را تأیید کرد. SQL idempotent برای SQL Server تولید شده ولی روی سرور واقعی اعمال نشده است. Migrationهای منتشرشده قبلی تغییر نکرده‌اند. چیدمان کارت About و آمار در این اصلاح تغییری نکرده و نتیجه مقایسه تصویری قبلی مربوط به همان چیدمان است.

## تصاویر مستقل مقالات

Release Build بدون خطا/هشدار، هر ۳۳ تست موفق و بدون skip، pending model changes خالی است. تست جدید آپلود هر دو نقش از فرم دارای CSRF، رد جایگاه تکراری بدون فایل اضافه، رد نقش تیم برای مقاله، منع تغییر به نقش اشغال‌شده، انتخاب مربع در فهرست و بنر در جزئیات/SEO و یکتایی index را بررسی می‌کند. تست مستقل fallback عمومی قدیمی و عدم استفاده از مربع اختصاصی به‌جای بنر اجرا شد. HTML layout، کلاس‌ها و CSS/JS اصلی تغییر نکردند؛ SQL ارتقا تولید شده ولی روی SQL Server واقعی در این محیط اجرا نشده است.

## حذف رسانه بدون نوع و بسته نمونه نسخه ۲

Release Build صفر خطا/هشدار، هر ۳۶ تست موفق و بدون skip، pending model changes خالی است. تست قبلی fallback با تست عدم جابه‌جایی تصویر بین نقش‌ها جایگزین شد، چون fallback صریحاً از نیاز حذف شده است. constraint نقش‌های صفر/۸ و لوگوی صریح بررسی شد. SamplePackageTests تمام ۲۰ محتوا و ۶۷ رکورد رسانه manifest را روی مدل واقعی EF/SQLite وارد و ۹ مسیر نمونه را رندر کرد. آپلود لوگو از فرم تنظیمات با نقش ۱۲ و بدون والد، دسترسی رسانه و حذف property IsCover تأیید شد.

هر چهار SQL (reset، schema کامل، sample و upgrade) با Microsoft.SqlServer.TransactSql.ScriptDom نسخه 180.140.0 و grammar SQL Server 160 بدون خطای نحوی parse شدند. این نتیجه اجرای واقعی SQL Server یا آزمون داده‌تبدیلی Migration روی آن نیست. هیچ reset روی DB واقعی این محیط اجرا نشده است.

ZIP نسخه۲ شامل ۶۷ JPEG با ابعاد نقش، ۳ اسکریپت، manifest و راهنماست؛ CRC، نام، تعداد، حجم، SHA256 و decode/ابعاد تصاویر کنترل شد. فایل‌های اصلی قالب و استایل تغییر نکردند. اسکریپت‌های تاریخی و تست‌های قدیمی در تاریخچه git حفظ‌اند ولی کد فعال و schema نهایی هیچ نقش عمومی و IsCover ندارند.
